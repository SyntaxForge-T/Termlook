TermLook user guide

Everything you need to organize your projects in TermLook. For installation, see the install section.

Getting started

TermLook opens a window with a workspace sidebar on the left and your terminals on the right. Each workspace holds tabs, and each tab holds up to four panes.

  • Press Ctrl+Shift+T for a new tab and Ctrl+Shift+N for a new workspace.
  • Split a pane left/right with Ctrl+Shift+E or top/bottom with Ctrl+Shift+D.
  • Resize dividers by dragging them, and swap panes by dragging their headers.
  • Press F1 for quick-start guidance, searchable shortcuts and customization help.

Print the default settings with termlook --print-default-settings.

Projects

  1. Open Projects… → Manage profiles, or Settings → Profiles.
  2. Choose a folder. Enter a project name, or leave it blank to use the folder name.
  3. Optionally choose a shell executable such as /bin/bash or /bin/zsh.
  4. Click Save project. Apply, Save and close and the settings window's close button also save the form.
  5. Open Projects…, select the project and click Open project.

Each profile opens its own workspace. Opening the same project again selects that workspace without creating a duplicate.

Saved profiles appear in a visible list above the settings form. Select a row to edit it, and use New project to create another. Invalid entries keep the settings window open and show an error. Discard changes cancels unsaved edits.

In Projects…, every profile has Edit and Delete buttons. Confirmed deletion is saved immediately. It removes the profile, while its folder, files and running terminals remain. Save or discard an open settings draft before deleting from the project manager.

Startup tasks and logs

In Settings → Profiles, enter one task per line using Name | command:

Server | npm run dev
Tests | npm test
Logs | tail -f app.log

These are examples; use commands that exist in your project. Leave the task field empty to open a normal terminal. Enable Run tasks automatically when I open this project, then save the profile.

  • Each task runs in its own terminal tab, concurrently, from the project folder.
  • Standard output and error output appear directly in the terminal.
  • Tabs show ▶ while running, ✓ on success, or ✗ with an exit code or termination signal.
  • Choose notifications for errors only, every completion, or off.
  • Open project launches the template once per workspace during the current app session.
  • Open + run tasks reruns a finished template in fresh tabs. It refuses while any template task is still running.

Use Ctrl+C to stop a foreground command, or close its tab with confirmation. Keep servers in the foreground rather than adding &, so their completion status follows the running process. Up to 12 tasks can be saved per profile.

Tasks use the selected shell with -c; interactive shell startup files may not load. Put required environment setup in the command or a project script. Failure status comes from the process exit status, not from matching words in logs. Desktop notifications require a notification service on your desktop.

Customization

Open Settings with Ctrl+,. Appearance changes apply to existing terminals without interrupting their shells.

Settings pageWhat you can change
AppearanceFont, text/background colors, ANSI palette, cursor, spacing, sidebar width and background image
TerminalShell, scrollback, bell and scrolling behavior
BehaviorClose-to-tray/minimize behavior and tab close buttons
ShortcutsApplication shortcuts; an empty binding disables the action
ProfilesProject names, folders, shells, startup tasks and notifications

For a custom background, select Appearance → Choose image…, choose a local image and adjust dimming and cover, contain or stretch fitting. Keep the image at its selected path. Supported formats depend on your system's image loader; common formats include PNG and JPEG.

Configuration files

Configuration lives in ~/.config/termlook/, or $XDG_CONFIG_HOME/termlook/:

FilePurpose
settings.jsonAppearance, shortcuts, profiles and tasks
layout.jsonWorkspace, tab, directory and pane layout
theme.cssOptional custom GTK interface styling

After editing configuration files, press Ctrl+Shift+R to reload. Invalid settings reloads leave the active settings unchanged.

F1 opens quick-start guidance, searchable shortcuts, customization help and Projects, a guide to project creation, tasks, logs and deletion. Tooltips reflect your configured shortcuts. Right-click a terminal for Copy/Paste; Ctrl+C retains its normal role of interrupting the foreground command.

Session behavior

Switching tabs or workspaces keeps opened sessions running. Restored tabs start their shells lazily when selected, while project tasks start when explicitly launched through the project workflow.

Restarting restores the layout, not running processes or scrollback. Logs remain in their tabs until the tab or application closes and are not automatically archived to disk. Open a profile from Projects… after restarting to launch its tasks again.

Directory tracking uses the shell's OSC 7 support; otherwise the initially configured directory is retained.

Background mode

With background mode enabled, closing the main window hides it if an AppIndicator host is available, or minimizes it otherwise. Use Quit to end the application. Optional Ubuntu tray integration:

sudo apt install libayatana-appindicator3-1 gnome-shell-extension-appindicator

Enable the desktop's AppIndicator extension. Disabling background mode makes window close ask before quitting. Native Windows is not supported; see the packaging notes for WSLg.
