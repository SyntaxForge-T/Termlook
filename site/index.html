Native Linux terminal

A workspace for every project.

Split panes, project profiles, startup tasks and live customization. Written in Rust with GTK 3 and VTE. Run your own shell, and watch commands and logs side by side.

Download the .deb package View on GitHub

Free and open source (MIT) · built and tested on Ubuntu 24.04 · Linux only

Everything a project needs, in one window

TermLook keeps each project in its own workspace, so you can switch context without stopping a running server or losing your layout.

Workspaces and tabs

Organize terminals by project and switch between them without stopping running commands.

Up to four panes per tab

Split horizontally or vertically, resize dividers, swap panes by dragging their headers, or focus a single pane.

Saved projects

Choose a folder and a shell, then open, edit or delete the profile from a visible list.

Startup tasks

Launch a project's commands in separate tabs with live output, exit status and optional desktop notifications.

Personal appearance

Change fonts, colors, cursor style, shortcuts and background images without restarting your shells.

Confirmed closing

Closing a pane, tab or workspace, or quitting, asks before ending sessions. No more lost work.

Layout restoration

Workspace names, tabs, directories and split geometry come back on the next launch.

Native and lightweight

Rust, GTK 3 and VTE. Lazy terminal creation and coalesced layout writes. No Python runtime required.

See it in action

Screenshots show a temporary demo project, not personal files.

Projects, one click away

Save a folder and shell as a project. Open it from Projects… and TermLook creates its workspace. Opening the same project again selects that workspace instead of creating a duplicate.

  • Edit or delete a profile right from the list.
  • Deleting a profile never touches its folder, files or running terminals.

Startup tasks with live logs

Describe your dev setup once, one Name | command per line, and open the whole project with a click. Each task runs in its own tab, from the project folder.

  • Tabs show ▶ while running, ✓ on success and ✗ with the exit code.
  • Notify on errors only, on every completion, or never.
  • Up to 12 tasks per profile.

Make it yours, live

Fonts, text and background colors, the ANSI palette, cursor style, spacing, sidebar width and a background image. Changes apply to existing terminals without interrupting their shells.

  • Remap or disable any application shortcut.
  • Add your own GTK styling with an optional theme.css.

Install TermLook

Use the prebuilt Debian package, or build it yourself. Native Windows is not supported.

Recommended Debian package

Download the .deb from the latest release, then install it:

sudo apt install ./termlook_*_amd64.deb

Verify the download with sha256sum -c SHA256SUMS. Needs Ubuntu 24.04 or newer on amd64.

Build from source

Needs Rust 1.88+ and the GTK and VTE development libraries:

sudo apt install build-essential pkg-config \
  libgtk-3-dev libvte-2.91-dev librsvg2-common
git clone https://github.com/SyntaxForge-T/Termlook.git
cd Termlook
cargo run --release --locked

Install for your user

From a checkout, install the binary and an application-menu entry without root:

./scripts/install_desktop.sh

Installs to ~/.local/bin/termlook. Add that folder to your PATH to launch it from other terminals.

Updating: quit the old instance completely before opening the new one. TermLook is a single-instance application, so launching it while an older copy runs just brings that window to the front.
